# 단타 차트 분석기 (daytrader)

일봉 차트를 기술적 지표로 분석해 **다음 거래일 단타 후보**를 점수화하는 프로그램입니다.

| 단계 | 기능 | 명령 |
|---|---|---|
| 1단계 | 내가 고른 종목 분석 | `python main.py analyze 삼성전자 000660 AAPL` |
| 2단계 (최종) | 전 종목 스캔 → 추천 | `python main.py scan` |
| 검증 | 점수가 실제 수익과 연결되는지 확인 | `python main.py validate` |

> ⚠ **현재 상태: 검증 결과 기본 전략에는 예측력이 확인되지 않았습니다.** 아래 「검증 결과」를 먼저 읽으세요.
> 본 프로그램은 참고용이며 수익을 보장하지 않습니다.

## 설치

```bash
pip install -r requirements.txt
```

- 데이터: [FinanceDataReader](https://github.com/FinanceData/FinanceDataReader) (국내 KRX 무료 시세 + 미국 주식)
- **장 마감(15:30) 이후 실행**을 권장합니다. 장중에 실행하면 당일 캔들이 미완성 상태로 계산됩니다.

## 사용법

### 1단계: 종목 직접 분석
```bash
python main.py analyze 삼성전자 SK하이닉스 에코프로 NVDA
```
종목별로 다음 내용을 보여줍니다.
- 단타 점수(0~100)와 등급 (A≥70 강한 후보 / B≥55 관심 / C≥40 관망 / D 비추천)
- 켜진 긍정 신호와 주의 신호
- 매매 계획: 진입가, 1·2차 목표가, 손절가 (ATR 기준)
- **해당 종목의 과거 1년 검증**: 같은 점수 이상의 신호가 났을 때 다음날 단타를 했다면 승률과 평균 수익이 어땠는지

### 2단계: 전 종목 스캔 후 추천
```bash
python main.py scan                          # 거래대금 상위 500종목 → 상위 20개 추천 (약 2분)
python main.py scan --market KOSDAQ --top 30
python main.py scan --limit 0                # 거래대금 30억 이상 전 종목
python main.py scan --require-edge           # 종목별 과거 검증 평균이 플러스인 종목만
```
- 우선주, 스팩, ETN, 리츠는 제외합니다. 당일 거래대금 30억 원 미만도 제외합니다(`--min-amount`로 조정).
- 결과는 `reports/` 폴더에 **CSV(엑셀용)**와 **HTML 리포트**로 저장됩니다.

## 점수 체계 (`daytrader/strategy.py`의 `SIGNALS`)

| 신호 | 가중치 |
|---|---|
| 정배열 (종가 > 5일선 > 20일선) | +15 |
| MACD 골든크로스 (최근 3일 내) | +15 |
| 거래량 급증 (20일 평균의 2배 이상 + 양봉) | +15 |
| RSI 50~70 / 20일 신고가 돌파 / 스토캐스틱 골든크로스 / 고가 부근 마감 | 각 +10 |
| 20일선 상승, MACD 히스토그램 확대, 거래량 1.5배, 볼린저 상단 돌파, ATR 2~8% | 각 +5 |
| 과열 (RSI 80 이상 또는 당일 +20% 이상) | −15 |
| 긴 윗꼬리, 60일선 아래 | 각 −10 |

가중치 표만 고치면 전략을 바꿀 수 있습니다. **고친 뒤에는 반드시 `validate`를 다시 실행하세요.**

## 검증 결과 (2026-11-11, 거래대금 상위 150종목 × 최근 약 1년)

```
점수구간  표본수  종가→익일시가%  익일시가→종가%  종가→익일종가%  시가→종가 승률%
0-20      19024        0.29           -0.02            0.28             45.6
20-40      5900        0.30           -0.13            0.16             44.0
40-55      3275        0.36           -0.02            0.33             43.8
55-70       829        0.23            0.03            0.26             45.2
70+         314        0.19           -0.72           -0.54             41.7

55점 이상 → 다음날 시가 매수, ±0.5ATR 익절/손절, 비용 0.25%: 1,143회, 승률 36.6%, 평균 -0.89%
```

**해석**
- 점수가 높아도 다음날 성과가 좋아지지 않았습니다. 오히려 70점 이상은 다음날 장중 평균 −0.72%였습니다. 급등과 거래량 폭증 다음 날에는 시가 갭 이후 되밀리는 경향이 있기 때문입니다.
- 「종가 매수 → 익일 시가 매도」는 모든 점수 구간에서 +0.2~0.4%였습니다. 하지만 이는 점수의 효과가 아니라 상승장 전반의 효과이며, 거래비용(약 0.25%)과 슬리피지를 빼면 거의 남지 않습니다.
- 즉, **교과서적인 '돌파 + 거래량' 매수 신호는 이 데이터에서 다음날 단타 우위가 없었습니다.**

**검증의 한계**: 기간이 1년뿐이고 생존 종목만 포함합니다(생존 편향). 일봉만 쓰기 때문에 같은 날 목표가와 손절가에 모두 닿으면 손절로 처리했습니다(보수적 가정).

## 다음 단계 제안
1. 점수 체계 재설계 후 `validate`로 확인하기 (예: 급등 다음 날 눌림목, 과매도 반등). 한 기간에서 찾은 규칙은 다른 기간에서도 재확인해야 합니다.
2. 분봉 데이터 연동 (증권사 API: 키움, 한국투자증권 등). 진짜 '당일' 단타는 일봉만으로 한계가 있습니다.
3. 매일 장 마감 후 자동 스캔과 결과 알림.

## 구조
```
main.py                  실행 (analyze / scan / validate)
daytrader/data.py        시세·종목목록 수집 (재시도 포함)
daytrader/indicators.py  이동평균, RSI, MACD, 볼린저, 스토캐스틱, ATR, 거래량 지표
daytrader/strategy.py    신호 판정, 점수화, 매매계획(진입/목표/손절)
daytrader/backtest.py    종목별 '다음날 단타' 백테스트
daytrader/analyzer.py    종목 1개 분석
daytrader/scanner.py     전 종목 스캔
daytrader/validate.py    전략 검증 (점수구간별 다음날 수익)
daytrader/report.py      콘솔 / CSV / HTML 출력
```
