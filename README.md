# 단타 차트 분석기 (daytrader)

장 마감 후 일봉 차트를 분석해 **다음 거래일 단타 후보**를 점수화합니다.
매매 방식은 **다음날 시가 매수 → 장 마감 직전 매도(당일 청산)**, 손절은 매수가 − 1×ATR입니다.

| 기능 | 명령 |
|---|---|
| 내가 고른 종목 분석 | `python main.py analyze 삼성전자 000660 에코프로` |
| 전 종목 스캔 → 시장 상태 판정 + 추천 | `python main.py scan` |
| 점수 체계 검증 | `python main.py validate` |

> 본 프로그램은 참고용이며 수익을 보장하지 않습니다. 실제 매매 전 소액·모의 매매로 먼저 확인하세요.

## 설치
```bash
pip install -r requirements.txt
```
- 데이터: [FinanceDataReader](https://github.com/FinanceData/FinanceDataReader) (국내 KRX 무료 시세 + 미국 주식)
- **장 마감(15:30) 이후 실행**하세요. 장중에는 당일 캔들이 미완성입니다.

## 전략: 과매도 반등형 (기본, `reversal`)

| 신호 | 가중치 |
|---|---|
| RSI(14) 30 미만 | +25 |
| 볼린저밴드 하단 이탈 | +20 |
| 당일 −7% 이하 급락 | +20 |
| 변동성 큼 (ATR 4% 초과) | +15 |
| 저가 부근 마감 (캔들 하단 20%) | +10 |
| RSI(2) 10 미만 | +10 |
| 당일 +10% 이상 급등 | −30 |
| 변동성 너무 작음 (ATR 2% 이하) | −15 |

추천 기준은 60점 이상입니다. 1차 버전의 돌파 추세형은 `--strategy momentum`으로 비교용으로만 남겼습니다.

### 가장 중요한 규칙: 시장 전반 투매일에만 매매
`scan`은 스캔한 종목 중 신호가 난 비율을 계산해 그날의 매매 여부를 판정합니다.

- **신호 비율 10% 이상 (시장 전반 투매일)** → ✅ 매매일
- **10% 미만 (소수 종목만 급락)** → ⛔ 매매 비추천. 개별 악재로 빠진 종목은 다음날에도 반등하지 않았습니다.

이런 투매일은 **1년에 8번 정도**뿐입니다. 대부분의 날은 "오늘은 쉬세요"가 정답입니다.

## 검증 결과 (2026-11-11 실행, 거래대금 상위 285종목, 2023-02 ~ 2026-11)

규칙은 앞 기간(~2025-06)에서 정하고, 뒤 기간(2025-07~)에서 다시 확인했습니다.
아래 수치는 모두 다음날 시가 매수 → 종가 매도 기준이고, 「초과」는 같은 날 전체 종목 평균 대비 수익입니다.

**점수 구간별 다음날 성과 (점수가 높을수록 좋아져야 정상)**

| 점수 | 앞 기간 초과 | 뒤 기간 초과 | 전체 승률 |
|---|---|---|---|
| 0-20 | −0.03% | −0.02% | 43.6% |
| 40-60 | +0.17% | +0.11% | 49.0% |
| 60-75 | +0.09% | +0.60% | 55.1% |
| 75+ | +0.61% | +0.67% | 59.5% |

**60점 이상 실제 매매 규칙 백테스트 (손절 1ATR, 비용 0.25% 차감)**

| 구분 | 거래수 | 승률 | 평균 수익 |
|---|---|---|---|
| 앞 기간 | 2,697 | 50.7% | +0.43% |
| 뒤 기간 | 1,641 | 59.7% | +1.28% |
| 2023 / 2024 / 2025 / 2026 | | | +0.19% / +0.79% / **−0.38%** / +1.50% |

**같은 날 신호가 난 종목 비율별 성과 (핵심)**

| 신호 비율 | 거래수 | 평균 수익 | 승률 |
|---|---|---|---|
| ~2% | 902 | −0.20% | 44.6% |
| 2-5% | 881 | +0.01% | 48.2% |
| 5-10% | 700 | −0.01% | 50.0% |
| **10% 이상** | 1,855 | **+1.85%** | 63.1% |

- 투매일은 4년간 32일이었습니다. 그중 65.6%의 날이 수익이었고, 하루 평균은 +0.96%였습니다.
- **최악의 날은 하루 평균 −11.8%였습니다** (2026-07-28). 2024-08-02(−6.8%)와 2025-04-07처럼 하락이 며칠 더 이어지면 크게 잃습니다. 2025년이 마이너스였던 것도 3~4월 급락장에서 반등 매수가 연속으로 실패했기 때문입니다.

비교로, 1차 버전 추세형의 같은 백테스트 결과는 앞 기간 −0.47%, 뒤 기간 −0.40%로 실패했습니다.

### 이 검증의 한계 (반드시 읽어 주세요)
1. **생존 편향**: 지금 상장돼 있고 거래가 활발한 종목만 검증했습니다. 폭락 후 상장폐지되거나 소외된 종목은 빠져 있습니다. 반등형 전략은 이 편향 때문에 결과가 실제보다 좋게 나올 수 있습니다.
2. **표본이 작음**: 수익은 대부분 32일의 투매일에서 나왔습니다. 거래가 1,855건이어도 같은 날 거래는 함께 움직이므로, 실제 독립 표본은 32개에 가깝습니다.
3. **규칙을 고르면서 전체 기간을 봤습니다**: '투매일에만' 규칙은 전체 데이터를 본 뒤에 찾았습니다. 앞으로의 실제(전진) 검증이 필요합니다.
4. 일봉만 사용합니다. 시가에 실제로 체결되는 가격, 슬리피지, 장중 손절 순서는 반영하지 못했습니다.

## 사용법 상세
```bash
python main.py scan --market KOSDAQ --top 30     # 코스닥만
python main.py validate --split 2025-07-01       # 앞/뒤 기간 경계 지정
python main.py --strategy momentum validate      # 1차 추세형과 비교
python main.py --threshold 70 scan               # 추천 기준 점수 변경
```
- 우선주, 스팩, ETN, 리츠, 당일 거래대금 30억 원 미만 종목, 상한가 마감 종목은 제외합니다.
- 결과는 `reports/` 폴더에 CSV(엑셀용)와 HTML로 저장됩니다.
- 전략을 바꾸려면 `daytrader/strategy.py`의 `signals` 가중치를 고치세요. **고친 뒤에는 반드시 `validate`를 다시 실행하세요.**

## 다음 단계 제안
1. **전진 검증**: 매일 스캔 결과를 기록해 실제 다음날 성과와 자동 비교합니다. 과거 검증의 한계를 보완하는 가장 확실한 방법입니다.
2. 분봉 데이터 연동 (증권사 API): 장중 손절 순서와 체결가를 정확히 반영합니다.
3. 매일 장 마감 후 자동 스캔과 알림.

## 구조
```
main.py                  실행 (analyze / scan / validate)
daytrader/data.py        시세·종목목록 수집 (재시도 포함)
daytrader/indicators.py  이동평균, RSI(14/2), MACD, 볼린저, 스토캐스틱, ATR, 거래량 지표
daytrader/strategy.py    전략 정의 (reversal 기본 / momentum 비교용), 점수화, 매매계획
daytrader/backtest.py    다음날 시가매수·종가매도 백테스트 (손절, 비용, 상한가 제외)
daytrader/analyzer.py    종목 1개 분석
daytrader/scanner.py     전 종목 스캔, 시장 상태(투매일) 판정
daytrader/validate.py    전략 검증 (점수구간·기간·연도·신호비율별)
daytrader/report.py      콘솔 / CSV / HTML 출력
```
